# VQA-Augmented Multimodal Meme Retrieval System

A multimodal meme search engine that combines structured VQA annotation, multilingual dense retrieval, and late fusion to deliver relevant results for both English and Russian queries. Deployed as a production Telegram bot.

## Overview

The system automatically analyzes meme images using a vision-language model, extracts structured semantic annotations across 10 fields including captions, objects, tone, emotions, meme templates, and search queries in both English and Russian. These annotations are encoded into dense vectors using bge-m3 and indexed in three separate FAISS indices. At query time, the system performs parallel searches across all indices, fuses results via Reciprocal Rank Fusion, and applies Maximal Marginal Relevance diversification before returning the top results to the user.

## Architecture

The retrieval pipeline consists of three stages. First, a mega-text index combines all annotation fields into a single dense vector per meme. Second, dedicated search query indices in English and Russian capture the intent-level semantics of each meme. Third, a CLIP-based image index supports reverse image search. At query time, results from the relevant indices are fused using weighted RRF with language-aware routing, meaning Russian queries automatically engage the Russian index with adjusted fusion weights. MMR post-processing with perceptual hash deduplication ensures diverse, non-redundant result pages.

The system supports three search modes: text search where users describe the meme they are looking for, image search where users send a reference image to find visually similar memes, and hybrid search combining both text and image inputs.

## Dataset

The corpus contains over 15,500 memes collected from six sources including Reddit, Imgflip, Bing Image Search, Telegram stickers, Memedroid, and Know Your Meme. After perceptual hash deduplication, approximately 9,700 unique memes remain indexed. Each meme is annotated with 10 structured VQA fields generated by gpt-5.4-mini-fast with vision capabilities. An automated Reddit scraper continuously adds new memes every 5 minutes while the bot is running, with automatic VQA annotation, NSFW filtering, and index updates.

## Results

### Retrieval metrics

Evaluation was conducted on 99 held-out test memes with 495 queries per language.

| Configuration | Hit@1 | Hit@5 | Hit@10 | MRR@10 |
|---|---|---|---|---|
| EN, 495 queries | 27.1% | 60.0% | 69.3% | 0.407 |
| RU, 495 queries | 26.3% | 57.0% | 60.8% | 0.397 |

This represents a significant improvement over the initial baseline: English Hit@5 increased from 32% to 60% and Russian Hit@5 increased from 2% to 57%.

### User satisfaction

A user-centric evaluation was performed with three human raters and LLM-as-a-Judge on 100 natural search queries, 50 in English and 50 in Russian.

| Metric | EN, 50 queries | RU, 50 queries | Overall |
|---|---|---|---|
| Relevance | 3.42 | 2.84 | 3.13 |
| Diversity | 3.68 | 3.76 | 3.72 |
| Satisfaction | 3.24 | 2.56 | 2.90 |

English queries score higher on relevance and satisfaction as expected given the predominantly English corpus. Diversity scores are comparable across languages, confirming that MMR re-ranking works effectively regardless of query language.

### Latency

Benchmarked on 199 queries running on Apple M-series hardware with a single thread.

| Stage | EN | RU |
|---|---|---|
| Query encoding, bge-m3 | 33.8 ms | 33.8 ms |
| FAISS search + RRF + MMR | 4.4 ms | 6.2 ms |
| Total | 38.2 ms | 40.0 ms |
| p95 | 56.7 ms | 60.0 ms |

Russian queries are slightly slower because they search three indices instead of two.

## Technology stack

The system is built with Python 3.13 and uses bge-m3 from SentenceTransformers as the multilingual embedding model, FAISS for approximate nearest neighbor search, CLIP ViT-B/32 for image embeddings, gpt-5.4-mini-fast for VQA annotation and search query generation, PaddleOCR for text extraction from images, and aiogram 3 for the Telegram bot interface. The Reddit scraper uses PRAW to collect memes from popular subreddits on a recurring schedule.

## Setup

```bash
git clone https://github.com/Ahamidullin/VQA-Augmented_Multimodal_Meme_Retrieval_System.git
cd VQA-Augmented_Multimodal_Meme_Retrieval_System
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Create a `.env` file with the following variables:

```
BOT_TOKEN=your_telegram_bot_token
OPENAI_API_KEY=your_openai_api_key
REDDIT_CLIENT_ID=your_reddit_client_id
REDDIT_CLIENT_SECRET=your_reddit_client_secret
```

Run the bot:

```bash
OMP_NUM_THREADS=1 python src/bot/main.py
```
